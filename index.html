🔴 Current Project
RHS One-Step — Right Hand Side Automation
A sophisticated end-to-end automation spanning Appian, Power Automate Cloud, Power Automate Desktop, Excel, and Dataverse. Uses an HTTP payload bridge to transfer data from Appian into work queues, runs multi-bot parallel processing, executes database CRUD operations, triggers Excel macros, and stores comprehensive logs in Dataverse.
Architecture Flow
🟦 Appian→ ☁️ Queue Bridge Dispatcher→ 📋 PA Work Queue→ 🖥️ Desktop Flow→ 🗄️ Dataverse Logs
Cloud Flow 1 — Queue Bridge Dispatcher
Acts as a bridge between Appian and Power Automate via HTTP payload. Receives incoming data and directly populates the PA Work Queue for structured downstream processing.
Desktop Flow — Queue Processor
Processes each work queue item with multi-layer data validation, runs CREATE / READ / UPDATE queries against the database, executes Excel macros, and updates Excel reports.
Cloud Flow 2 — RHS Queue Pulse Performer
Implements multi-bot architecture — orchestrates parallel execution of desktop flows across multiple machines. Stores all flow logs in Dataverse for monitoring and auditing.
